# iPhone 6 11대역 stitching 측정본 인벤토리

작성일: 2026-10-23. 원본은 읽기 전용으로 검사했다. 실제 신호 처리와 MATLAB 실행은 메인 작업에서 수행한다.

## 측정 조건과 확인 수준

사용자 진술: iPhone 6, USRP-2940R, 순시대역폭 120 MHz, 외부 LNA/BPF 없음, 프로브 측정, clamp로 프로브와 폰 위치 고정. 중심주파수는 100–700 MHz를 60 MHz 간격으로 이동한 11개 파일이다. 명목상 인접 overlap는 60 MHz, 50%다. **사용자 추가 확인: Fs = 124.0828 MS/s (복소 IQ).** 원 진술 표기는 `124.0828MHz`이며 메인 에이전트가 전달한 사용자 clarification으로 기록했다. 120 MHz 순시대역폭과 저장 샘플링률 124.0828 MS/s를 구별한다.

[기존 하드웨어 검토](../hardware_notes.md)는 120 MHz RF 대역폭 옵션과 최대 200 MS/s IQ rate를 구분한다. 이번 기록은 사용자가 밝힌 실제 측정 조건을 채택하지만, 실물 설정에서 Fs·gain·clock·overflow를 직접 읽었다고 주장하지 않는다. Fs의 근거는 사용자 확인이다.

Nominal RF 합집합은 40–760 MHz, 폭 720 MHz이다. 이는 각 파일의 유효 통과대역이 fc±60 MHz라는 가정으로 계산한 기하학적 범위다. 필터 roll-off, 실제 Fs, DC 부근과 가장자리의 신뢰도를 검증하기 전에는 720 MHz의 유효 신호가 확보되었다고 해석하지 않는다.

첫 1 MiB의 BE 해석은 모든 파일에서 작은 signed-int16 샘플 분포를 보였다. LE 해석은 큰 byte-swap wrap 값과 rail 부근 값이 생긴다. 이전 측정본의 저장 형식과 함께 **big-endian int16 I,Q, header=0**이 강한 후보이다. 생산 VI를 직접 확인한 것은 아니므로 후보/분석 convention으로 기록한다. I+jQ 부호와 절대 RF 축 방향은 stitching overlap에서 별도로 검증해야 한다. 첫 1 MiB에서 BE int16 rail clipping은 없지만 전체 파일 무클리핑 판정은 하지 않았다.

각 파일 첫/끝 1 MiB의 byte offset, length, SHA-256, BE/LE 통계를 [JSON](CAPTURE_INVENTORY.json)에 기록했다. 추가 확인 단계에서 11개 전체 파일을 순차 스트리밍으로 읽어 full-file SHA-256도 계산했다. 완료 UTC: 2026-10-23T09:37:39.708Z, 읽기·해시 계산 누적 35.356초. endpoint hash는 full-file hash를 대체하지 않는다. 모든 파일 크기가 29,700,000 bytes의 배수이지만 buffer 단위만으로 Fs를 추정하지 않는다.

## Fs 메타데이터 탐색 결과와 사용자 확인

Downloads/Desktop와 현재 연구 폴더의 .m/.txt/.json/.md/.csv에서 해당 파일명이나 black글 문자열을 검색했지만 일치하는 sidecar를 찾지 못했다. 최근 파일을 확인한 결과:

- Desktop/EMC SIPI/test2.m: 2026-10-22 수정. HDMI/TMDS 다른 실험에 Fs=148.5 MHz가 등장하므로 이번 파일로 전이하지 않는다.
- Desktop/figure notation.pptx: 2026-10-22 수정. 슬라이드 텍스트는 HDMI 방어 실험이며 해당 11개 측정본의 샘플링률을 제공하지 않는다.
- raw 수정시각은 2026-10-23 09:10–09:28 UTC 근처지만 복사·다운로드 시각일 수 있다. 측정순서와 측정 시작시간으로 사용하지 않는다.

이 검색 이후 사용자가 Fs=124.0828 MS/s를 확인했으므로 이 값을 신호 처리 기준으로 사용한다. requested/coerced rate의 장비 로그, gain, reference clock, overflow/dropped samples, 실제 수집순서와 시작시각은 여전히 미확인이다. duration은 int16 I/Q 샘플 수를 사용자 확인 Fs로 나눈 계산값이다.
